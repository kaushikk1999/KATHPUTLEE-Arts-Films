# Kathputlee Arts & Films

Welcome to the official repository for the Kathputlee Arts & Films website. 
This project is a cinematic, premium, high-conversion frontend architecture tailored for film studios, production houses, and creative agencies.

## Live Deployment

🚀 **View the live website here:** [https://kathputlee-arts-films.vercel.app/](https://kathputlee-arts-films.vercel.app/)

## Tech Stack

- **Framework:** React + Vite
- **Routing:** React Router v6
- **Styling:** Custom CSS with Glassmorphism and Cinematic Theming
- **Icons:** Lucide React & Google Material Symbols

## Local Development

To run this project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/kaushikk1999/KATHPUTLEE-Arts-Films.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Design Highlights

- **Cinematic Overlays:** Integrated `film-grain`, `ken-burns` zoom effects, and reactive `#spotlight` mouse tracking for a moody, neo-noir aesthetic.
- **Scroll Reveal Architecture:** Uses `IntersectionObserver` to stagger and fade elements smoothly into view as the user scrolls.
- **Dynamic Routing:** Fully configured SPA routing with `vercel.json` rewrites to prevent 404 errors on deep linking (e.g. `/brand-services`, `/originals`).
